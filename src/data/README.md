# Game data

Generated by the data export: don't edit these files by hand. `items.json`, `entities.json`, `monsters.json` and `slugs.json` are rewritten on every export.

## Where the game's names and texts come from

English is the game's own text. Every other language comes from the game client's translation tables: the players' client (0.2.6) wherever it ships a table, and the original game's client only where it ships none. Each table comes from one client: a language is never mixed.

| Table | Portuguese | Spanish |
|---|---|---|
| Actor | the players' client (0.2.6) | the original game's client |
| Enum | the players' client (0.2.6) | the original game's client |
| Item | the players' client (0.2.6) | the original game's client |
| Quest | the players' client (0.2.6) | the original game's client |
| Spell | the players' client (0.2.6) | the original game's client |
| Track | the players' client (0.2.6) | the original game's client |

The English item type names come from the players' client (0.2.6).

The players' client ships no tables in Spanish today, so those come from the original game's client.

A name or text the tables don't have shows in English, marked: `_fb` lists the languages that fell back. Item type names a client language doesn't have (the original Spanish client's are English) are the wiki's own.
